# 技能正文可达性审计(2026-11-25)

`summary.json` 是结论与口径;`audit.mjs` 可在任何一台机器上对自己的会话历史重跑(只读, 只输出计数):

```
node website/evidence/experiments/skill-reach-2026-11-25/audit.mjs
```

- **问题**:自进化晋升的技能,在真实会话里有没有被模型读到正文?
- **结果**:注入了技能的 2228 个会话里,只有 43 个(1.9%)读到过任何 `SKILL.md`;77 次读取里 23 次因为路径猜错而失败。
- **原因**:系统提示词的技能清单只有 `- 名字: 描述`,不带文件位置;另外清单里 120 行有 65 行的描述是字面的 `name: <技能名>`(CRLF frontmatter 没被解析)。
- **修复**:清单每行加子目录标记,系统提示词给出"标记 → 路径"的图例;描述提取规范化换行并支持折叠块标量。

只发布计数,不发布任何会话内容。
