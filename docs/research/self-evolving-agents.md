# 自进化智能体研究报告（2024–2026）

调研方式：arxiv.org 直连被阻断，转用 OpenAlex API，DOI 已核对。

## 1. Voyager 式技能库
- **关键工作**：Voyager（2023，技能库范式开创者，arXiv 2305.16291）；SkillWeaver（2025，Web 智能体自主发现并打磨技能，arXiv 2504.07079）；SkillRL（ACL 2026，用 RL 信号校验技能）；ACE（2025，增量式上下文进化，arXiv 2510.04618）；综述 arXiv 2512.16301。
- **核心机制**：技能=可执行代码+描述，按任务相似度检索；晋升门禁=环境反馈+执行错误+自验证三重迭代通过才入库（Voyager）。改进方向：技能精炼/合并（SkillWeaver）、RL 校验（SkillRL）、增量更新防上下文坍缩（ACE）。Voyager 无显式淘汰机制。
- **工程启示**：技能须带验证记录与使用统计；淘汰用"降级归档"而非物理删除；入库门禁独立于生成者自评。

## 2. 自我修改智能体：DGM / AlphaEvolve / ADAS
- **关键工作**：DGM（2025，归档式进化自我修改代码的智能体，doi 10.70777/si.v2i3.15063）；AlphaEvolve（2025，DeepMind 进化式编码智能体，arXiv 2506.13131）；ADAS（2024，元智能体自动搜索智能体设计空间，arXiv 2408.08435）；Gödel Agent（2024，自指式自我改进，arXiv 2410.04444）。
- **核心机制**：共同门禁是**经验验证**——DGM 每次自我修改后用编码基准实测，通过才进归档；归档保存多样谱系，采样父代再变异；AlphaEvolve 用自动评估器反馈驱动进化；ADAS 的 Meta Agent Search 以代码迭代生成并评测新设计。另：EMNLP 2025 发现全量历史塞进元模型上下文反而降效（doi 10.18653/v1/2025.findings-emnlp.1135）。
- **工程启示**：门禁=沙箱实测而非自评；谱系归档支持回滚；元模型上下文精选而非全量历史。

## 3. 记忆系统
- **关键工作**：MemGPT（2023，OS 式分层虚拟上下文管理，arXiv 2310.08560）；A-MEM（2025，Zettelkasten 式动态记忆组织）；Mem0（2025，生产级抽取-巩固-检索，arXiv 2504.19413）；MemoryOS（EMNLP 2025）；综述（ACM TOIS 2025，doi 10.1145/3748302）。
- **核心机制**：分层存储、主动巩固压缩、按需换页。关于"只增不删"：Self-Improvising Memory（Entropy 2024）主张记忆保持"显著性而非保真度"；Mem0/MemoryOS 均含删除/合并——**蒸馏与遗忘是共识**，纯只增会导致检索噪声。风险：MEXTRA（ACL 2025）证明记忆可被提示攻击批量提取。
- **工程启示**：定期蒸馏成精炼知识，旧条目归档不删除；记忆写入防注入防投毒。

## 4. 评估方法论
- **关键工作**：AgentBench（2023，8 环境评测，arXiv 2308.03688）；τ-bench（2024，工具-智能体-用户交互，以数据库状态校验成败，arXiv 2406.12045）及 τ²-bench（2025，双控制）；LiveCodeBench（2024，滚动新题防污染，arXiv 2403.07974）；Leak, Cheat, Repeat（EACL 2024，污染综述）；AI Agents That Matter（2024，arXiv 2407.01502）。
- **核心机制**：防背题三招——时间窗口化（只用模型截止日后新题）、滚动更新、保留集隔离；τ 系列以环境终态而非自述判定成败；AI Agents That Matter 要求成本与成功率双报。2026 年研究（arXiv 2606.09863）证实 τ²-bench 上"虚假成功"（自称完成但环境未变）普遍存在。
- **工程启示**：进化集与验收保留集严格分离；成功判定基于文本无关的环境状态。

## 5. 定时/离线进化循环
- **关键工作**：自进化智能体综述（2025，arXiv 2508.07407，闭环四组件：输入-系统-环境-优化器）；ExpeL（AAAI 2024，离线收集轨迹后蒸馏经验，不更新权重）；AWM（2024，从轨迹归纳可复用工作流，arXiv 2409.07429）。
- **核心机制**：进化与在线服务解耦——离线优化器批处理轨迹，元模型起草候选技能/工作流，验证后入库；DGM/AlphaEvolve 的归档采样+并行评估适合后台异步；Voyager 自动课程产技能。
- **工程启示**："起草-验证-晋升"做成定时批处理；候选技能先入暂存区，验收合格才进生产库。

## 6. 安全边界
- **关键工作**：BadAgent（ACL 2024，智能体后门攻击）；Agent Security Bench（2024，攻防基准，arXiv 2410.02644）；间接提示注入（2023，doi 10.1145/3605764.3623985）；IsolateGPT（NDSS 2025，执行隔离）；MEXTRA（ACL 2025）。
- **核心机制**：威胁面=技能/记忆写入通道可投毒、工具调用可注入、第三方技能不可信。对策：执行隔离与最小权限、不可信内容降级为纯数据、高危操作人工确认。DGM 自身也冻结基座模型、只进化脚手架并要求验证。
- **工程启示**：自学习技能与人工技能分权；涉及写操作/外发的技能晋升需人工批准。

## 自进化闭环最佳实践清单
1. 晋升门禁唯一依据=沙箱内自动验证通过，禁用生成者自评（DGM、Voyager）。
2. 进化集与验收保留集严格隔离，防背题、防回退（LiveCodeBench、AI Agents That Matter）。
3. 评测集时间窗口化并滚动更新（LiveCodeBench）。
4. 谱系归档：每个技能记录来源、验证分数、父代，支持回滚审计（DGM）。
5. 淘汰=降级归档而非删除，依据使用率与保留集成功率（ACE、Self-Improvising Memory）。
6. 双指标门禁：成功率+成本，防复杂度膨胀（AI Agents That Matter）。
7. 成功判定基于文本无关的环境真值，防"虚假成功"（arXiv 2606.09863）。
8. 技能/记忆写入通道视为不可信输入，入库前做投毒/注入检测（BadAgent、ASB、MEXTRA）。
9. 离线定时批量进化：元模型起草候选→暂存→验收→晋升，与在线服务解耦（自进化综述、ExpeL、AWM）。
10. 冻结基座模型与高危工具权限，只进化脚手架/技能层，高危变更人工批准（DGM、IsolateGPT）。
