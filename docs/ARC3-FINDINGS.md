# ARC-AGI-3 研究发现总档

> 定位（2026-09-29 定案）：ARC-AGI-3 在 hmharness 中**考的是 harness（框架），不训练大模型**。
> 模型权重从不更新，分数变化=框架净贡献。本文档汇总 2026-09 至 2026-10-22 的全部实验定论，
> 所有数字可由 scripts/arc3-*.mts 仪器在本机语料上复跑验证。

## 一、校准证据链（三种独立形态一致）

语料规模：31 → 41 → 51 → 71 → 91 → 111 → 134 条轨迹（2022 步），两日增长 4.3 倍。

| 证据形态 | 方法 | 结果 |
|---|---|---|
| **随机分割**（七档规模） | 70/30 分割，5 种子，预测专用评分 | **晋升恒 5/5**（均值相对改进 0.963-0.994，符号检验 p=0.0313） |
| **时间维曲线**（部署形态） | 按时间五等分桶，训练于过去、评分于当桶 | Brier **1.0 → 0.0077**（空白模型恒 ~1.0） |
| **迁移实验**（LLM 未参与） | arc3→arc3 双臂，纯探索引擎 | 校准差 **+0.4166** = 100% 框架贡献 |

**终局结论：harness 层（世界模型信念表）在 ARC-AGI-3 上产生分割鲁棒、时间鲁棒、
与模型无关的校准净贡献。** 训练后 Brier 最低 0.0005（空白 ~1.0）。

## 二、对局诚实边界（三策略关卡全 0）

| 策略 | 单局耗时 | 动作覆盖 | 视觉成本 | 关卡 |
|---|---|---|---|---|
| 探索引擎（不确定性驱动） | **~10 秒** | 智能分配（专打低置信动作） | **零** | 0 |
| LLM（glm-5.3-flash 视觉） | ~5 分钟 | 低多样性 | 低 | 0 |
| LLM（glm-5.3 主模型视觉） | ~5 分钟 | **单动作坍缩**（每局 1 类型） | 高 | 0 |

- 121+ 局 LLM 对局零过关；**主模型档位测试排除"视觉模型不够强"假设**（flash 与主模型同样 0 关）
- §26 消融（认知层 vs 裸提示，同模型同游戏）：**双臂 0 关，净贡献 +0 关**（17 次实验 0 正/17 平/0 负）
  ——校准贡献≠对局贡献，与 v0.24 P2A 的"校准不自动转化为任务成功"定律同构
- **ARC-AGI-3 关卡对当前所有模型档位同等难（基准设计本意）；项目价值锚定在校准与预测**

## 三、逐动作结构（校准信号的真实分布）

| 动作类型 | 语料占比 | 成功率 | WM 信念 | 考题 Brier |
|---|---|---|---|---|
| ACTION1 | 53% | 1.000 | 0.985 | 0.0002 |
| ACTION6 | 31% | 1.000 | 0.994 | 0.0000 |
| ACTION3 | 9% | 0.949 | 0.826（欠自信） | 0.0634 |
| ACTION4 | 1% | **0.875** | 0.922（**过度自信**） | **0.1116** |
| ACTION7 | 1% | 1.000 | 0.860（样本极少） | 0.0196 |

**发现：主流动作（84% 语料）平凡可测；校准信号集中于稀有可变动作（ACTION3/4/7）。
这解释了三臂 learned-vs-frozen 边距随语料构成波动（7→4→7→7→2/9）的机理——
边距取决于考题中稀有动作的占比。逐动作视角是三臂仪器一直建议的透镜，至此清偿。**

## 四、成本对比

探索引擎 = LLM 对局的 **1/30 时间 + 零视觉 API 成本**，且产出假设裁决全过的
多样化轨迹——校准飞轮最便宜的燃料（迁移实验 +0.4166 即用纯探索轨迹取得）。

## 六、诚实边界清单（绝不宣称）

- 不宣称 ARC 关卡通过率提升（三策略全 0 关）
- 不宣称认知层改善对局（消融 17 次全持平）
- 不宣称三臂边距稳健（随语料构成波动，已定档为不稳健）
- 唯一持久主张：**校准净贡献的鲁棒性**（随机七档 + 时间曲线 + 迁移三形态一致）
