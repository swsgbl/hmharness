hmharness

自 进 化 · 零 依 赖

为鸿蒙 (HarmonyOS/OpenHarmony) 开发全流程而生的自进化智能体框架 —— 零依赖内核 + 自进化一等公民 + MCP 生态借力。一句话创建工程、构建、装机、跑模拟器;每一步进化都有基准门禁与回滚。

不继承任何上游,全部自持

七包单仓:零依赖内核 + 自进化 + 鸿蒙原生域 + 运维看家 + 执行层 + 双前端。while 循环内核、上下文压缩、审批门禁、会话审计全部自研,MCP 生态即插即用。

四步上手

Node ≥ 22 + 鸿蒙工具链(hvigorw / hdc / DevEco 或命令行等价物)。任意 OpenAI 兼容厂商均可。

1
克隆并构建
git clone https://github.com/swsgbl/hmharness.git
cd hmharness && npm install && npm run build
npm link -w @hmh/cli
2
初始化并配置厂商(任意 OpenAI 兼容端点;支持多厂商按用途路由)
hmh init
notepad %USERPROFILE%\.hmharness\config.json
  { "provider": { "baseUrl": "…", "apiKey": "…", "model": "…" } }
3
一条命令起飞:全屏 TUI,网页端自动就绪
hmh tui          # 全屏 TUI + 自动后台启动网页端
hmh web start    # 或单独后台启动网页(零窗口,stop/status)
4
让它自己变强
hmh evolve --every=30   # 常驻自进化(双门禁,回归即回滚)

严格提升,否则回退

借鉴 Darwin Gödel Machine 与 GDPevo 的机制教训:每轮优化有度量、有快照、防背题、可回滚;进化循环无法触碰配置与安全设置。
