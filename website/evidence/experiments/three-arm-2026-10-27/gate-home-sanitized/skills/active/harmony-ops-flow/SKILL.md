# HarmonyOS Ops Workflow

Three-step operational check for HarmonyOS environments.

## Step 1 — Radar Brief

harmony_ops_radar_brief

Returns a high-level overview of the current ops state.

## Step 2 — Status Check

harmony_ops_status

Query detailed device/build status.

## Step 3 — Radar Scan

harmony_ops_radar_scan

Scan for issues, mismatches, or recommended actions.

## Example
bash
harmony_ops_radar_brief
harmony_ops_status
harmony_ops_radar_scan

Always run all three in order for a complete picture.
