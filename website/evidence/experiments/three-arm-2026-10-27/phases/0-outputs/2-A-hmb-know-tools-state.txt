## `hmh evolution snapshot`

在 hmharness 中,对演化状态(skills / memory / insights)做快照用于恢复的子命令是:

```
hmh evolution snapshot
```

它会把 `HMH_HOME` 下的 skills、memory、insights 打成一个带时间戳的快照,配合恢复选项(如 `hmh evolution restore --latest`)即可回滚到之前的演化状态。

调用一次即可看到当前快照列表:`hmh evolution snapshot --list`。
