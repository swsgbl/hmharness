hmharness

自 进 化 · 零 依 赖

为鸿蒙 (HarmonyOS/OpenHarmony) 开发全流程而生的自进化智能体框架 —— 零依赖内核 + 自进化一等公民 + MCP 生态借力。一句话创建工程、构建、装机、跑模拟器;每一步进化都有基准门禁与回滚。

⭐ GitHub 开源 四步上手 模拟器全链路证明 快速开始验证矩阵
$ hmh tui ⚙ hmharness · your-model · my-app · ○ idle 网页端已就绪 → http://127.0.0.1:7788 ❯ 创建鸿蒙工程 my-app:登录页+首页,构建装进模拟器跑起来 ● harmony_project_create → pages+modules · OK ● harmony_build → hvigorw · BUILD SUCCESSFUL ● harmony_emulator_start → running ● harmony_install → harmony_launch → ✓ ability started

不继承任何上游,全部自持

16 包单仓:零依赖内核 + 经验自进化(用得越多越聪明) + 鸿蒙原生域 + 运维看家 + 执行层 + 双前端。while 循环内核、上下文压缩、审批门禁、会话审计全部自研,MCP 生态即插即用。

🏗️

参数化工程脚手架

harmony_project_create 一次调用生成多页面 + feature HAP + har 库的任意结构;hvigor 真实构建验证。

🖥️

模拟器全生命周期(零 IDE)

harmony_emulator_* 直接驱动官方无头 CLI:发现/目录/创建/启动/停止/删除,全系机型与变体即刻部署,无需打开 DevEco Studio。

📲

构建 · 装机 · 运行

hvigor 构建、hdc 安装/启动/日志/卸载、仓颉 cjpm 构建、官方 codelinter 门禁 —— 设备写操作全部走审批。

🧠

自进化双门禁

洞察挖掘 → 技能提案 → 训练门 A/B 基准(双样本,运气过不了门)→ 晋升进金丝雀(20% 会话采样)→ impact 判定(≥8 会话且 ≥10% 差才转正,有害即退役)→ 回归即回滚;判定记录原样发布在证据页。

🔌

MCP 双向生态

客户端:手写零依赖(stdio + Streamable HTTP),5800+ 社区服务器即插即用;服务器:hmh mcp-serve 把鸿蒙工具链以原生工具供给 Claude Code / Codex / 任意 MCP 宿主,按工具名粒度豁免审批。

🛰️

运维看家(生态雷达)

8 源开源鸿蒙雷达每日 diff 脚手架与门禁假设,模型写简报、模板降级;issue 流 AI 只起草、人批准才发布,draft PR + 身份署名。

🎛️

双前端

全屏 TUI(斜杠面板 ↑↓ 选择、滚轮翻页、/resume 会话恢复选择器、右对齐输入气泡、内置更新提醒)+ Web(浏览器审批、会话回放、工作区切换);hmh tui 一条命令自动带起网页端。

🛡️

安全内建

deny-first 审批门禁做进循环内核;破坏性命令模式硬拒绝;进化提案过防投毒筛选;会话全量追加式审计;hmh state backup 进化状态一键快照与恢复。

🌍

国际化 & 多厂商

zh / en 双语界面与系统提示(--locale=en);任意 OpenAI 兼容厂商按用途路由(chat / vision / evolve / bench)。

📐

模型感知上下文工程

上下文窗口登记表,压缩预算随模型窗口自适应(128K=旧默认,未知模型零变化);超长会话滚动摘要(被逐内容先蒸馏再丢弃);工作区记忆隔离;可选 embedding 混合检索。

认知层 — harness 从经验中学习，有学习曲线为证

世界模型从每次任务的工具轨迹中学习并反哺系统提示;探索引擎优先探测模型预测最差的动作(预测误差=信息增益);校准可靠度随使用提升 — 五环境曲线全有读数,四环境 improving。这不是宣称,是 hmh cognitive calibration --trend 的输出。

🌐

世界模型与校准

信念表(每动作成功率)+ 预测置信 + 误差聚类 + 可解释修订;每个任务步自动带预测,校准报告按动作列可靠度 — 迁移双臂实验证明 harness 净贡献 +0.4166(LLM 未参与)。

🎮

ARC-AGI-3 官方桥

官方 REST API 全桥(cookie 亲和/scorecard/ACTION1-7);帧渲染为图像,视觉模型看帧推理选动作,模型原话随 reasoning 入档;记分卡+行动效率/探索效率指标。

🔀

跨环境迁移

显式抽象动作层(writeFile→@write / hdc-install→@install);双臂对照实验(源环境信念播种 vs 空白,同预算只差知识);迁移矩阵面板。

🧾

五层记忆 + 数据治理

working/episodic/semantic/procedural/world 五层,只增不删+完整溯源(来源/会话/环境/时间);矛盾检测打标待审;cognitive export 单文件全量导出、purge 显式确认删除。

🤖

多智能体治理

spawn_agent 全部走角色契约拓扑 + 共享预算 + 跨进程不可变审计(multi-agent.jsonl);supervisor 可看心跳/超时/取消级联。

📱

手机远程控制

WiFi 扫码直连(免密)+ cloudflared 免费隧道互联网模式(6 位配对密码);配对会话持久化,服务器重启不重扫;断线自动重连。

四步上手

Node ≥ 22 + 鸿蒙工具链(hvigorw / hdc / DevEco 或命令行等价物)。任意 OpenAI 兼容厂商均可。

A
标准桌面:直接用 npm
npm install -g @hmharness/cli
B
贡献者 / 源码优先
git clone https://github.com/swsgbl/hmharness.git
npm install && npm run build
完整贡献安装文档
C
KaihongOS / OpenHarmony 板端
node scripts/install-kaihongos.cjs

安装后先运行 hmh check | devices 验证工具链与设备；反馈环境问题时请附脱敏输出，或按 快速开始验证矩阵 分流首错。

下面是标准 npm 路径的四步流程；源码与板端边界见仓库 README 和板端指南。

1
npm 安装(已发布,零构建)
npm install -g @hmharness/cli   # Node >= 22
2
初始化并配置厂商(任意 OpenAI 兼容端点;支持多厂商按用途路由)
hmh init
notepad %USERPROFILE%\.hmharness\config.json
  { "provider": { "baseUrl": "…", "apiKey": "…", "model": "…" } }
3
一条命令起飞:全屏 TUI,网页端自动就绪
hmh tui          # 全屏 TUI + 自动后台启动网页端
hmh web start    # 或单独后台启动网页(零窗口,stop/status)
4
让它自己变强
hmh evolve --every=30   # 常驻自进化(双门禁,回归即回滚)
