如何在你自己的环境复现

复现依赖你的本机工具链与模拟器状态；hmharness 不提供绕过厂商渠道的模拟器镜像下载。先确认 hdc list targets 能看到目标，再运行公开脚本：

git clone https://github.com/swsgbl/hmharness.git
cd hmharness
npm install && npm run build
npx tsx scripts/e2e-device.mts 127.0.0.1:5555

顺序执行到最终输出 DEVICE E2E COMPLETE 后，再核对 install、launch、hilog 与 uninstall 输出；若失败，保留脱敏后的第一步错误输出，并带到 环境反馈 Discussion。
